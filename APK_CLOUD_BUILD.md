# Облачная сборка APK (без Android Studio)

Ты выбрал вариант, где APK собирается в облаке, а ты просто скачиваешь файл.

## Что уже сделано

- В проект добавлен GitHub Actions workflow: `.github/workflows/android-apk.yml`.
- Он собирает Android APK и кладет его в артефакты.

## Что нужно сделать тебе

1. Загрузить этот проект в GitHub (новый репозиторий).
2. Открыть вкладку **Actions**.
3. Выбрать workflow **Build Android APK**.
4. Нажать **Run workflow**.
5. Дождаться завершения (зеленая галка).
6. Внизу запуска скачать артефакт **gradus-android-apk**.
7. Внутри будет `app-release.apk`.

## Установка на Android

1. Передай `app-release.apk` на телефон.
2. Открой файл в менеджере файлов.
3. Разреши установку из этого источника.
4. Установи приложение.
5. На экране появится иконка **Градус**.
